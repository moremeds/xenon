# Apex R2 ETL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move historical OHLCV + TA indicator computation out of the scanner into a nightly GitHub Action that writes Parquet to Cloudflare R2 (`apex-data` bucket). Scanner becomes a pure consumer: sync R2 → local mirror → join universe.json → classify bullish/bearish.

**Architecture:** Producer/consumer split. GitHub Action (unlimited wall-clock, isolated secrets) reads `meta/universe.json` from R2, fetches OHLCV from Massive, computes TA indicators, and writes per-ticker Parquet files to `parquet/historical/{tf}/` and `parquet/indicators/{tf}/`. Local scanner calls `apex_sync.sync_if_stale()` at startup, loads parquets into memory via pyarrow, joins the universe metadata, and runs Stage A/B/C classification.

**Tech Stack:** Python 3.13, boto3 (R2 S3-compatible API), pyarrow (Parquet), pandas, ta-lib, pytest + moto for R2 mocking, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-04-16-apex-r2-etl-design.md`

### A8 (I, Task 3) — `_normalize_timestamp` must be DST-safe

`dt.tz_localize("America/New_York")` on spring-forward / fall-back wall-clock raises. The legacy HKT-labelled parquets may contain any intraday value; a single `2024-03-10 02:30:00` would turn the scanner sync into a hard failure.

**Fix:**

```python
if series.dt.tz is None:
    return series.dt.tz_localize(_ET, ambiguous="infer", nonexistent="shift_forward").dt.tz_convert(_UTC)
if str(series.dt.tz) != _UTC:
    return (
        series.dt.tz_localize(None)
        .dt.tz_localize(_ET, ambiguous="infer", nonexistent="shift_forward")
        .dt.tz_convert(_UTC)
    )
return series
```

Add a test case covering `2024-03-10 02:30:00` (spring-forward gap) and `2024-11-03 01:30:00` (fall-back ambiguous).

### A13 (I, Task 8) — Atomic mirror swap (spec §4)

Spec §4 line 194-195: _"Atomic: writes to `mirror_dir.tmp/` then `rename`."_ The plan writes directly to `mirror_dir`. A scanner started mid-sync can observe a partial mirror.

**Fix:**

### A16 (I, Task 7) — Manifest ETag retry loop

Spec §3 manifest: _"Retry on mismatch with exponential backoff."_ Plan's single `put_json(..., if_match=prev_etag)` raises `R2PreconditionError` on race.

**Fix:** wrap the head/get/put in a bounded loop:

```python
for attempt in range(3):
    try:
        prev = r2.head("meta/last_updated.json")
        prev_etag = prev["ETag"] if prev else None
        existing = r2.get_json("meta/last_updated.json") if prev else {}
        manifest = {**existing, "historical": now, "indicators": now, "schema_version": _SCHEMA_VERSION}
        r2.put_json("meta/last_updated.json", manifest, if_match=prev_etag)
        break
    except R2PreconditionError:
        if attempt == 2:
            raise
        time.sleep(2 ** attempt)
```

### A17 (I, Task 5/6) — `--dry-run` must actually redirect writes

Spec §4 line 168 + runbook line 2304 reference `data/apex_mirror_preview/`, but `refresh_one` writes to `r2.put_object` unconditionally.

**Fix:** Introduce a minimal sink abstraction in `r2_store.py`:

```python
class DryRunStore:
    """Local-filesystem stand-in for R2Store; used under --dry-run."""
    def __init__(self, root: Path): self._root = root
    def put_object(self, key: str, body: bytes, if_match=None): (self._root / key).parent.mkdir(parents=True, exist_ok=True); (self._root / key).write_bytes(body); return '"dryrun"'
    def put_json(self, key, data, if_match=None): ...
    def get_object(self, key): return (self._root / key).read_bytes()
    def get_json(self, key): return json.loads(self.get_object(key))
    def head(self, key): return {"ETag": '"dryrun"'} if (self._root / key).exists() else None
    def list_objects(self, prefix): yield from ((str(p.relative_to(self._root)), p.stat().st_size, None) for p in (self._root / prefix).rglob("*") if p.is_file())
```

`main()`:

```python
if args.dry_run:
    r2 = DryRunStore(_PROJECT_ROOT / "data" / "apex_mirror_preview")
else:
    r2 = R2Store()
```

```python
def _tickers_with_data(mirror_dir: Path, universe_rows: list[dict], timeframes: tuple[str, ...]) -> tuple[list[dict], list[str]]:
```

### A20 (I, Task 11 + spec §6) — Reconcile RSI threshold: spec says `rsi > 50`, code says `rsi > 40`

`passes_bullish_gate` in `scripts/trend_scan_lib/stages/ta_prefilter.py:157` is `rsi > 40`; spec §6 line 313 says `rsi > 50`. The plan leaves this unchanged. Not a plan bug, but a documented drift that should be resolved explicitly.

### A21 (M, Task 7) — 50% failure-ratio boundary untested

`failure_ratio > _FAILURE_RATIO_ABORT` (strict `>`) means exactly 50% (e.g., 1 of 2 tickers failed) is accepted. Combined with A4, the manifest would still be written on 1/2 failure.

**Fix:** Keep strict `>` (intended: "only abort on truly catastrophic runs") but add three tests: 0% failure, exactly 50%, 51% (1 fail in 2, 5 fail in 10, 6 fail in 10). Document the threshold rationale in the docstring.

### A22 (M, Task 7) — Shared `MassiveClient` across 10 threads

`MassiveClient` docstring says "Thread-safe for read operations via shared Session", but `requests.Session` with heavy concurrent use can hit `urllib3` connection-pool exhaustion (`HTTPConnectionPool is full`) or rarely corrupt response chunking. Low risk but observable.

**Fix:** Either (a) reduce `max_workers` default to 5, or (b) instantiate a per-thread `MassiveClient` in the `ThreadPoolExecutor` initializer. Don't block on this — flag it in the PR for observation during the one-week soak.

```python
"""Cloudflare R2 S3-compatible wrapper.

Sole owner of boto3 S3 calls within the xenon codebase. Everything else
goes through R2Store to keep retry policy and error mapping centralized.
"""
from __future__ import annotations

import json
import logging
import os
from dataclasses import dataclass
from datetime import datetime
from typing import Iterator

import boto3
from botocore.config import Config
from botocore.exceptions import ClientError

logger = logging.getLogger(__name__)


class R2Error(Exception):
    """Base class."""


class R2NotFoundError(R2Error):
    """Object missing (404)."""


class R2PreconditionError(R2Error):
    """If-Match failed (412)."""


class R2ClientError(R2Error):
    """Non-retryable 4xx."""


@dataclass(frozen=True)
class _Config:
    endpoint: str
    bucket: str
    access_key: str
    secret_key: str

    @classmethod
    def from_env(cls) -> "_Config":
        try:
            return cls(
                endpoint=os.environ["R2_ENDPOINT"],
                bucket=os.environ["R2_BUCKET"],
                access_key=os.environ["R2_ACCESS_KEY_ID"],
                secret_key=os.environ["R2_SECRET_ACCESS_KEY"],
            )
        except KeyError as exc:
            raise R2Error(f"Missing R2 env var: {exc.args[0]}") from exc


class R2Store:
    """Thin S3 wrapper with retry, ETag support, and typed errors."""

    def __init__(self, config: _Config | None = None):
        self._cfg = config or _Config.from_env()
        self._client = boto3.client(
            "s3",
            endpoint_url=self._cfg.endpoint,
            aws_access_key_id=self._cfg.access_key,
            aws_secret_access_key=self._cfg.secret_key,
            region_name="auto",
            config=Config(
                retries={"max_attempts": 3, "mode": "adaptive"},
                connect_timeout=10,
                read_timeout=60,
            ),
        )

    @property
    def bucket(self) -> str:
        return self._cfg.bucket

    def get_object(self, key: str) -> bytes:
        try:
            resp = self._client.get_object(Bucket=self.bucket, Key=key)
            return resp["Body"].read()
        except ClientError as exc:
            code = exc.response.get("Error", {}).get("Code")
            if code in ("NoSuchKey", "404"):
                raise R2NotFoundError(key) from exc
            raise R2ClientError(f"get_object({key!r}): {code}") from exc

    def put_object(self, key: str, body: bytes, if_match: str | None = None) -> str:
        kwargs: dict = {"Bucket": self.bucket, "Key": key, "Body": body}
        if if_match is not None:
            kwargs["IfMatch"] = if_match
        try:
            resp = self._client.put_object(**kwargs)
            return resp["ETag"]
        except ClientError as exc:
            code = exc.response.get("Error", {}).get("Code")
            if code in ("PreconditionFailed", "412"):
                raise R2PreconditionError(key) from exc
            raise R2ClientError(f"put_object({key!r}): {code}") from exc

    def head(self, key: str) -> dict | None:
        try:
            return self._client.head_object(Bucket=self.bucket, Key=key)
        except ClientError as exc:
            if exc.response.get("Error", {}).get("Code") in ("NoSuchKey", "404", "NotFound"):
                return None
            raise R2ClientError(f"head({key!r})") from exc

    def list_objects(self, prefix: str) -> Iterator[tuple[str, int, datetime]]:
        paginator = self._client.get_paginator("list_objects_v2")
        for page in paginator.paginate(Bucket=self.bucket, Prefix=prefix):
            for obj in page.get("Contents", []):
                yield obj["Key"], obj["Size"], obj["LastModified"]

    def get_json(self, key: str) -> dict:
        return json.loads(self.get_object(key).decode("utf-8"))

    def put_json(self, key: str, data: dict, if_match: str | None = None) -> str:
        body = json.dumps(data, default=str).encode("utf-8")
        return self.put_object(key, body, if_match=if_match)
```

```python
"""Parquet I/O for OHLCV and indicator snapshots.

Writers always emit timestamp[us, tz=UTC]. Readers normalize the legacy
tz=Asia/Hong_Kong label (producer bug: wall-clock values are actually
America/New_York) by stripping the tz, re-localizing to ET, and converting
to UTC. Also drops the pandas reset_index residue column __index_level_0__.
"""
from __future__ import annotations

from typing import IO

import pandas as pd
import pyarrow as pa
import pyarrow.parquet as pq

OHLCV_COLUMNS: tuple[str, ...] = ("timestamp", "open", "high", "low", "close", "volume")

INDICATOR_COLUMNS: tuple[str, ...] = (
    "timestamp",
    "sma_20", "sma_50", "sma_200",
    "rsi_14", "adx_14",
    "macd", "macd_signal", "macd_histogram",
    "bb_upper", "bb_middle", "bb_lower", "bb_width",
    "atr_14",
    "high_20d", "low_20d", "high_52w", "low_52w",
    "up_day_volume_ratio",
)

_ET = "America/New_York"
_UTC = "UTC"


def _validate_columns(df: pd.DataFrame, required: tuple[str, ...]) -> None:
    missing = [c for c in required if c not in df.columns]
    if missing:
        raise ValueError(f"missing columns: {missing}")


def _normalize_timestamp(series: pd.Series) -> pd.Series:
    """Return series with UTC-aware timestamps.

    If the series is naive, treat as ET. If it carries any tz other than UTC
    (the HKT-producer bug), strip the tz and re-localize as ET, then convert.
    """
    if series.dt.tz is None:
        return series.dt.tz_localize(_ET).dt.tz_convert(_UTC)
    if str(series.dt.tz) != _UTC:
        return series.dt.tz_localize(None).dt.tz_localize(_ET).dt.tz_convert(_UTC)
    return series


def _to_utc_us_table(df: pd.DataFrame, columns: tuple[str, ...]) -> pa.Table:
    """Coerce timestamp to UTC microsecond and project only declared columns."""
    out = df.loc[:, list(columns)].copy()
    out["timestamp"] = _normalize_timestamp(pd.to_datetime(out["timestamp"]))
    schema_fields = []
    for col in columns:
        if col == "timestamp":
            schema_fields.append(pa.field(col, pa.timestamp("us", tz="UTC")))
        elif col == "volume":
            schema_fields.append(pa.field(col, pa.int64()))
        else:
            schema_fields.append(pa.field(col, pa.float64()))
    return pa.Table.from_pandas(out, schema=pa.schema(schema_fields), preserve_index=False)


def write_ohlcv(sink: IO[bytes] | str, df: pd.DataFrame) -> None:
    _validate_columns(df, OHLCV_COLUMNS)
    table = _to_utc_us_table(df, OHLCV_COLUMNS)
    pq.write_table(table, sink)


def write_indicators(sink: IO[bytes] | str, df: pd.DataFrame) -> None:
    _validate_columns(df, INDICATOR_COLUMNS)
    table = _to_utc_us_table(df, INDICATOR_COLUMNS)
    pq.write_table(table, sink)


def _read_and_normalize(source: IO[bytes] | str, columns: tuple[str, ...]) -> pd.DataFrame:
    table = pq.read_table(source)
    df = table.to_pandas()
    df = df.drop(columns=["__index_level_0__"], errors="ignore")
    df["timestamp"] = _normalize_timestamp(pd.to_datetime(df["timestamp"]))
    missing = [c for c in columns if c not in df.columns]
    if missing:
        raise ValueError(f"parquet missing required columns: {missing}")
    return df.loc[:, list(columns)].reset_index(drop=True)


def read_ohlcv(source: IO[bytes] | str) -> pd.DataFrame:
    return _read_and_normalize(source, OHLCV_COLUMNS)


def read_indicators(source: IO[bytes] | str) -> pd.DataFrame:
    return _read_and_normalize(source, INDICATOR_COLUMNS)


def dedupe_concat(base: pd.DataFrame, new: pd.DataFrame) -> pd.DataFrame:
    """Concatenate, dropping duplicate timestamps preferring `new` values."""
    combined = pd.concat([base, new], ignore_index=True)
    combined = combined.drop_duplicates(subset=["timestamp"], keep="last")
    return combined.sort_values("timestamp").reset_index(drop=True)
```

```python
def load_universe(r2) -> list[dict]:
    """Read meta/universe.json from R2 and return the `tickers` list.

    turnover_rate, timeframes[] (authoritative timeframes for that ticker).
    """
    payload = r2.get_json("meta/universe.json")
    tickers = payload.get("tickers") or []
    if not tickers:

def expand_targets(
    universe: Iterable[dict],
    *,
    timeframes: tuple[str, ...] = _DEFAULT_TIMEFRAMES,
) -> Iterator[tuple[str, str]]:
    """Yield (ticker, timeframe) pairs — intersection of requested and ticker's own list."""
    tf_set = set(timeframes)
    for row in universe:
        symbol = row.get("symbol")
        allowed = set(row.get("timeframes") or [])
        if not symbol:
            continue
        for tf in tf_set & allowed:
            yield symbol, tf
```

```python
import io
from dataclasses import dataclass
from datetime import date, timedelta

import pandas as pd

_FULL_LOOKBACK_DAYS = 730  # 2 years for cold-start / full refresh


@dataclass
class RefreshResult:
    ticker: str
    timeframe: str
    succeeded: bool
    rows_written: int = 0
    error: str | None = None


def _compute_indicators_adapter(ohlcv: pd.DataFrame) -> pd.DataFrame:
    """Run TA-Lib indicator set, return only indicator columns + timestamp."""
    from scripts.ta_lib.indicators import compute_all

    enriched = compute_all(ohlcv.set_index("timestamp"))
    enriched = enriched.reset_index()
    # Derived columns that indicators.py doesn't own yet — compute here
    enriched["high_20d"] = enriched["high"].rolling(20, min_periods=1).max()
    enriched["low_20d"] = enriched["low"].rolling(20, min_periods=1).min()
    enriched["high_52w"] = enriched["high"].rolling(252, min_periods=1).max()
    enriched["low_52w"] = enriched["low"].rolling(252, min_periods=1).min()
    up = (enriched["close"] >= enriched["open"]).astype(float) * enriched["volume"]
    enriched["up_day_volume_ratio"] = up.rolling(20, min_periods=1).sum() / enriched[
        "volume"
    ].rolling(20, min_periods=1).sum()

    from scripts.ta_lib.parquet_store import INDICATOR_COLUMNS

    return enriched.loc[:, list(INDICATOR_COLUMNS)]


def refresh_one(
    *,
    r2,
    massive,
    ticker: str,
    timeframe: str,
    mode: str,
) -> RefreshResult:
    """Refresh a single (ticker, timeframe) pair. Never raises — returns RefreshResult."""
    from scripts.ta_lib.parquet_store import read_ohlcv, write_ohlcv, write_indicators, dedupe_concat

    hist_key = f"parquet/historical/{timeframe}/{ticker}.parquet"
    ind_key = f"parquet/indicators/{timeframe}/{ticker}.parquet"

    try:
        if mode == "full":
            start = date.today() - timedelta(days=_FULL_LOOKBACK_DAYS)
            bars = massive.fetch_ohlcv(ticker, timeframe=timeframe, start=start, end=date.today())
            ohlcv = bars
        else:  # incremental
            try:
                existing = read_ohlcv(io.BytesIO(r2.get_object(hist_key)))
                last_ts = existing["timestamp"].max()
                start = (last_ts + pd.Timedelta(days=1)).date()
            except Exception:
                existing = None
                start = date.today() - timedelta(days=_FULL_LOOKBACK_DAYS)
            new_bars = massive.fetch_ohlcv(ticker, timeframe=timeframe, start=start, end=date.today())
            ohlcv = dedupe_concat(existing, new_bars) if existing is not None else new_bars

        if ohlcv is None or len(ohlcv) == 0:
            return RefreshResult(ticker, timeframe, succeeded=False, error="empty OHLCV result")

        # Write historical
        hist_buf = io.BytesIO()
        write_ohlcv(hist_buf, ohlcv)
        r2.put_object(hist_key, hist_buf.getvalue())

        # Compute + write indicators
        indicators = _compute_indicators_adapter(ohlcv)
        ind_buf = io.BytesIO()
        write_indicators(ind_buf, indicators)
        r2.put_object(ind_key, ind_buf.getvalue())

        return RefreshResult(ticker, timeframe, succeeded=True, rows_written=len(ohlcv))
    except Exception as exc:  # noqa: BLE001
        return RefreshResult(
            ticker,
            timeframe,
            succeeded=False,
            error=f"{type(exc).__name__}: {exc}",
        )
```

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
from datetime import datetime, timezone

_FAILURE_RATIO_ABORT = 0.50
_SCHEMA_VERSION = 1


def _now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


def run_refresh(
    *,
    r2,
    mode: str,
    timeframes: tuple[str, ...],
    max_workers: int,
) -> int:
    """Full orchestrator. Returns 0 on success, 3 if failure_ratio > 50%, 1 on other error."""
    from scripts.clients.massive_client import MassiveClient

    universe = load_universe(r2)
    targets = list(expand_targets(universe, timeframes=timeframes))
    logger.info("Refreshing %d targets in %s mode", len(targets), mode)

    massive = MassiveClient()
    results: list[RefreshResult] = []

    with ThreadPoolExecutor(max_workers=max_workers) as ex:
        futures = [
            ex.submit(refresh_one, r2=r2, massive=massive, ticker=t, timeframe=tf, mode=mode)
            for t, tf in targets
        ]
        for fut in as_completed(futures):
            res = fut.result()
            results.append(res)
            if not res.succeeded:
                logger.warning("refresh failed: %s/%s — %s", res.ticker, res.timeframe, res.error)

    failed = [r for r in results if not r.succeeded]
    failure_ratio = len(failed) / max(len(results), 1)
    logger.info("Done. %d ok, %d failed (%.1f%%)", len(results) - len(failed), len(failed), failure_ratio * 100)

    # Update manifest atomically (conditional PUT with If-Match)
    try:
        prev = r2.head("meta/last_updated.json")
        prev_etag = prev["ETag"] if prev else None
        existing = r2.get_json("meta/last_updated.json") if prev else {}
    except Exception:
        existing, prev_etag = {}, None

    manifest = dict(existing)
    now = _now_iso()
    manifest["historical"] = now
    manifest["indicators"] = now
    manifest["schema_version"] = _SCHEMA_VERSION

    r2.put_json("meta/last_updated.json", manifest, if_match=prev_etag)

    # Write data_quality summary
    dq = {
        "generated_at": now,
        "mode": mode,
        "total_entries": len(results),
        "by_status": {
            "PASS": len(results) - len(failed),
            "FAIL": len(failed),
        },
        "failures": [
            {"symbol": r.ticker, "timeframe": r.timeframe, "error": r.error}
            for r in failed[:200]  # cap to keep the file bounded
        ],
    }
    r2.put_json("meta/data_quality.json", dq)

    if failure_ratio > _FAILURE_RATIO_ABORT:
        return 3
    return 0
```

```python
"""Scanner-side R2 → local mirror sync.

Gated by meta/last_updated.json. If local mirror is as fresh as R2, skip.
Otherwise parallel-download all parquet/historical and parquet/indicators
for the requested timeframes, plus meta/universe.json.
"""
from __future__ import annotations

import json
import logging
from concurrent.futures import ThreadPoolExecutor, as_completed
from dataclasses import dataclass, field
from pathlib import Path

logger = logging.getLogger(__name__)

_SUPPORTED_SCHEMA_VERSIONS = {1}


class SchemaVersionError(RuntimeError):
    """Remote manifest carries a schema version we don't know how to read."""


@dataclass
class SyncResult:
    synced: bool
    stale_reason: str | None = None
    files_downloaded: int = 0
    errors: list[str] = field(default_factory=list)


def _load_local_last_sync(mirror_dir: Path) -> dict:
    path = mirror_dir / ".last_sync.json"
    if not path.exists():
        return {}
    try:
        return json.loads(path.read_text())
    except json.JSONDecodeError:
        logger.warning("Corrupt %s; treating as empty", path)
        return {}


def _save_local_last_sync(mirror_dir: Path, payload: dict) -> None:
    mirror_dir.mkdir(parents=True, exist_ok=True)
    (mirror_dir / ".last_sync.json").write_text(json.dumps(payload))


def _is_stale(local: dict, remote: dict) -> str | None:
    for key in ("historical", "indicators"):
        lv = local.get(key)
        rv = remote.get(key)
        if rv is None:
            return f"remote missing {key}"
        if lv is None or lv < rv:
            return f"{key} stale (local={lv}, remote={rv})"
    return None


def _download_prefix(r2, prefix: str, mirror_dir: Path, max_workers: int) -> tuple[int, list[str]]:
    keys = [k for k, _size, _mtime in r2.list_objects(prefix)]
    errors: list[str] = []
    downloaded = 0

    def _one(key: str) -> None:
        nonlocal downloaded
        try:
            body = r2.get_object(key)
            target = mirror_dir / key
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(body)
            downloaded += 1
        except Exception as exc:  # noqa: BLE001
            errors.append(f"{key}: {exc}")

    with ThreadPoolExecutor(max_workers=max_workers) as ex:
        list(ex.map(_one, keys))

    return downloaded, errors


def sync_if_stale(
    *,
    mirror_dir: Path = Path("data/apex_mirror"),
    r2=None,
    timeframes: tuple[str, ...] = ("1d", "1h"),
    force: bool = False,
    max_workers: int = 10,
) -> SyncResult:
    if r2 is None:
        from scripts.ta_lib.r2_store import R2Store
        r2 = R2Store()

    remote = r2.get_json("meta/last_updated.json")
    schema = remote.get("schema_version")
    if schema not in _SUPPORTED_SCHEMA_VERSIONS:
        raise SchemaVersionError(
            f"remote schema_version={schema}, supported={_SUPPORTED_SCHEMA_VERSIONS}"
        )

    local = _load_local_last_sync(mirror_dir)
    stale = _is_stale(local, remote) if not force else "force=True"
    if stale is None:
        return SyncResult(synced=False)

    logger.info("apex mirror stale: %s; syncing", stale)
    total_files = 0
    all_errors: list[str] = []
    for tf in timeframes:
        for kind in ("historical", "indicators"):
            prefix = f"parquet/{kind}/{tf}/"
            n, errs = _download_prefix(r2, prefix, mirror_dir, max_workers)
            total_files += n
            all_errors.extend(errs)

    # Also refresh universe.json — Stage A joins against it
    (mirror_dir / "meta").mkdir(parents=True, exist_ok=True)
    try:
        (mirror_dir / "meta" / "universe.json").write_bytes(r2.get_object("meta/universe.json"))
        total_files += 1
    except Exception as exc:  # noqa: BLE001
        all_errors.append(f"meta/universe.json: {exc}")

    _save_local_last_sync(mirror_dir, {
        "historical": remote.get("historical"),
        "indicators": remote.get("indicators"),
        "schema_version": remote.get("schema_version"),
    })

    return SyncResult(
        synced=True, stale_reason=stale, files_downloaded=total_files, errors=all_errors
    )
```

```python
"""TAService — read-through view over the local Apex R2 parquet mirror.

Scanner-side consumer API. No DuckDB, no Massive client, no cache refresh
logic — those responsibilities live in the GitHub Action.
"""
from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

import pandas as pd

from scripts.ta_lib.parquet_store import read_indicators, read_ohlcv

logger = logging.getLogger(__name__)

# Rename map: parquet indicator column → scanner-expected key (kept for backwards compat)
_FIELD_MAP = {
    "sma_20": "ma_20",
    "sma_50": "ma_50",
    "sma_200": "ma_200",
    "rsi_14": "rsi",
    "adx_14": "adx",
    "bb_width": "bbw",
}


class TAService:
    """Read-only service backed by local parquet mirror."""

    def __init__(self, mirror_dir: Path | str = "data/apex_mirror"):
        self._mirror = Path(mirror_dir)

    def _hist_path(self, ticker: str, timeframe: str) -> Path:
        return self._mirror / "parquet" / "historical" / timeframe / f"{ticker}.parquet"

    def _ind_path(self, ticker: str, timeframe: str) -> Path:
        return self._mirror / "parquet" / "indicators" / timeframe / f"{ticker}.parquet"

    def get_ohlcv(self, ticker: str, timeframe: str = "1d") -> pd.DataFrame | None:
        path = self._hist_path(ticker, timeframe)
        if not path.exists():
            return None
        return read_ohlcv(str(path))

    def get_indicators(self, ticker: str, timeframe: str = "1d") -> pd.DataFrame | None:
        path = self._ind_path(ticker, timeframe)
        if not path.exists():
            return None
        return read_indicators(str(path))

    def get_snapshot(self, ticker: str, timeframe: str = "1d") -> dict[str, Any] | None:
        """Return the latest row merged {ohlcv + indicators} with scanner-friendly names."""
        ohlcv = self.get_ohlcv(ticker, timeframe)
        ind = self.get_indicators(ticker, timeframe)
        if ohlcv is None or len(ohlcv) == 0 or ind is None or len(ind) == 0:
            return None

        last_ohlcv = ohlcv.iloc[-1].to_dict()
        last_ind = ind.iloc[-1].to_dict()
        snap: dict[str, Any] = {
            "ticker": ticker,
            "timeframe": timeframe,
            "close": float(last_ohlcv.get("close", 0.0)),
            "open": float(last_ohlcv.get("open", 0.0)),
            "high": float(last_ohlcv.get("high", 0.0)),
            "low": float(last_ohlcv.get("low", 0.0)),
            "volume": float(last_ohlcv.get("volume", 0.0)),
            "dollar_volume": float(last_ohlcv.get("close", 0.0)) * float(last_ohlcv.get("volume", 0.0)),
            "price": float(last_ohlcv.get("close", 0.0)),
        }
        for col, value in last_ind.items():
            if col == "timestamp":
                continue
            renamed = _FIELD_MAP.get(col, col)
            try:
                snap[renamed] = float(value) if pd.notna(value) else 0.0
            except (TypeError, ValueError):
                snap[renamed] = 0.0
        return snap
```

```yaml
name: Apex Data Refresh

on:
  schedule:
    # Mon-Fri after US close: Tue-Sat 00:00 UTC = Mon-Fri 7-8 PM ET (DST-dependent)
    - cron: "0 0 * * 2-6"

  workflow_dispatch:
    inputs:
      mode:
        description: "Refresh mode"
        required: true
        default: "incremental"
        type: choice
        options: [incremental, full]
      timeframes:
        description: "Comma-separated timeframes"
        required: false
        default: "1d,1h"

permissions:
  contents: read

concurrency:
  group: apex-data-refresh
  cancel-in-progress: false

jobs:
  refresh:
    runs-on: ubuntu-24.04
    timeout-minutes: 90
    env:
      MASSIVE_API_KEY: ${{ secrets.MASSIVE_API_KEY }}
      R2_ENDPOINT: ${{ secrets.R2_ENDPOINT }}
      R2_BUCKET: ${{ secrets.R2_BUCKET }}
      R2_ACCESS_KEY_ID: ${{ secrets.R2_ACCESS_KEY_ID }}
      R2_SECRET_ACCESS_KEY: ${{ secrets.R2_SECRET_ACCESS_KEY }}
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.13"

      - name: Install TA-Lib C library
        run: |
          sudo apt-get update
          sudo apt-get install -y ta-lib

      - name: Install Python dependencies
        run: |
          python -m pip install --upgrade pip
          pip install boto3 pyarrow pandas requests python-dotenv ta-lib

      - name: Determine mode from trigger
        id: mode
        run: |
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then
            echo "mode=${{ github.event.inputs.mode }}" >> "$GITHUB_OUTPUT"
            echo "timeframes=${{ github.event.inputs.timeframes }}" >> "$GITHUB_OUTPUT"
          elif [ "${{ github.event.schedule }}" = "0 5 * * 6" ]; then
            echo "mode=full" >> "$GITHUB_OUTPUT"
            echo "timeframes=1d,1h" >> "$GITHUB_OUTPUT"
          else
            echo "mode=incremental" >> "$GITHUB_OUTPUT"
            echo "timeframes=1d,1h" >> "$GITHUB_OUTPUT"
          fi

      - name: Run apex_refresh
        run: |
          python scripts/apex_refresh.py \
            --mode "${{ steps.mode.outputs.mode }}" \
            --timeframes "${{ steps.mode.outputs.timeframes }}" \
            --max-workers 10
```
